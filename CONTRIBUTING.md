# Contributing

Thank you for looking. Widsith's source is published so that anyone can read it, as Blizzard's add-on policy asks, and so that you can see exactly what it records.

For now, pull requests are not merged. The addon is young and changes quickly, and its author would rather keep one hand on it until it has settled. That may change later.

If something is wrong, or you have an idea, the best places are the Discord server linked from the addon's About page (`/widsith about`) or an email to info@widsith.app. A recording that shows the problem, `Widsith.lua` from your `SavedVariables` folder, is the most useful thing you can send.
